本版处理范围（对应用户要求的五项）
  1. 手机端适配：增加小屏横向溢出保护、触控区域、对话框和地图容器约束；需在真实 iOS/Android 设备复核视觉效果。
  2. 交互：统一关键行动按钮状态、键盘焦点样式；保留办事、外交、军事、经济等原有交互。自动化测试覆盖主要入口，未逐一穷举每种角色/阵营组合。
  3. 存档：自动存档与手动槽同步；读档校验结构并兼容旧版自动存档；导入/导出仍使用 JSON 文件。
  4. 历史流程：1945年不再触发终局；1948年根据玩家选择和国势指标判定战后路线；可推进至1972年。
  5. 长期运行：新历史分支和国家指标写入存档；旧存档缺少新字段时自动补齐；修正1945年提前写入 ending 的问题。

新增战后分歧
  - 国民政府改革成功：宪政、反腐、渐进土地改革与政治协商可累积改革分；达到条件后，1949年不触发中华人民共和国成立事件，改为宪政转型路线。
  - 联合政府路线：政治协商与停战得分较高时，进入联合政府与区域自治阶段。
  - 中共取得全国政权：中共影响分较高时，1949年触发中华人民共和国成立。
  - 长期分治路线：双方均无稳定优势时，地方势力持续存在。
  - 1950、1953、1956、1966、1971年的战后事件会随路线变化，不再所有路线共用同一套史实事件。
  - 领袖可通过宪政、反腐、渐进土地改革、停战谈判等国策改变国家指标和历史走向。

V4.4.0 本轮新增（重点覆盖1949年以前）
  - 1898年戊戌变法新增君主立宪、责任内阁与地方自治方向。
  - 1912年中华民国成立事件新增八种制度蓝图：美国式总统制联邦、英国式议会内阁、瑞士式联邦委员会、法国式议会共和、魏玛式半总统、君主立宪、苏维埃一党体制、地方自治联邦/邦联。
  - 领袖国策中可在之后改选制度方向，支持较晚开始游戏的玩家。
  - 每种制度同时列出优势与风险；制度选择影响国势与1948年战后路线权重，但不会自动保证某阵营获胜。
  - 制度选择与变更历史写入存档；旧存档缺少字段时自动兼容。

制度设计说明
  美国式路线不是简单照搬美国，而是总统制、两院制、联邦分权、司法审查与权力制衡的组合；具体能否运转取决于军队国家化、财政能力、政党组织与地方自治。
  瑞士式联邦委员会、英国议会内阁、法国议会共和与魏玛双首长制均作为可比较的制度原型。
  苏维埃式一党体制与地方自治联邦作为非自由民主方向/权力结构对照，游戏会呈现其动员能力与监督、协调风险。

V4.7.0 权限闭环与存档防护
  - 增加制度提案审议：国家最高决策者可在制度面板查看具名制度蓝图提案，并选择采纳施行或归档；未指定具体组合的原则性建议不会被自动当作修宪授权。

V4.15.0 连续历史事件、多分支因果与动态世界状态
  - 以1936年西安事变为分水岭，新增跨年度因果链：1937年第二次国共合作与统一战线、1938年战区协调、1939年长沙会战、1941年皖南事变后的联络/恶化、1942年灾荒救济、1945年重庆谈判、1946年停战执行或破裂、1948年局部停火或战略决战。
  - 选项结果写入 historyChain.flags / outcomes；旧存档自动补齐，不覆盖既有 historyFlags、altHistory、eventOffers 和 internalPolitics。
  - 新增动态世界指标：政治稳定、经济韧性、战争压力、外交空间、社会凝聚、国际环境。指标逐年演变，并小幅反馈国家秩序、财政、民心、经济和世界力量值。
  - 新增“动态世界局势”卡片，展示指标和最近的历史因果记录。
  - 同一事件根据前序选择开放不同选项；例如西安事变和平解决更容易形成统一战线和战区协调，强硬路线会增加战争压力并压缩后续合作空间。
  - 1941年皖南事变仍保留为真实历史危机节点，不会因前期合作而自动消失；前期选择只改变危机后的交涉空间和游戏分支。
  - 该系统属于历史模拟的抽象因果模型，数值与分支是玩法设计，不代表历史事件存在唯一必然结果。
